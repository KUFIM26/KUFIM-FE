# 긴급 신고 화면 구현

Figma KUFIM의 E-1, E-2(중단 팝업 포함), E-3, W-1, W-2를 기존 React 화면에 구현했다.

- 방문자: `/report`, `/report/new`, `/report/:id`
- 총괄 관리자: `/admin/reports`, `/admin/reports/:id`
- 실제 백엔드 `PublicReportApiController`, `AdminReportApiController`, `ReportService`의 경로·요청·응답 형식에 맞춰 연결했다. 별도 목 모드를 추가하지 않았다.
- 상세 열람 시 접수 요청, 메모 저장 시 처리 중 전환, 완료 처리 확인을 적용했다. 상태 직접 선택 UI는 백엔드 동작에 맞게 변경했다.
- 백엔드 제약에 따라 이름은 10자, 장소는 50자이며 신고 유형을 추가했다. 방문자 응답에는 전화번호가 없으므로 이름만 표시한다. 관리자 전체 번호는 연락처 보기 요청 후에 표시한다.
- 상태 색은 Figma의 회색·녹색 계열을 따른다. 취소는 별도 탭과 붉은 배지로 표시한다.
- `VITE_CONTROL_ROOM_PHONE`에 실제 상황실 전화번호를 지정해야 전화 버튼을 사용할 수 있다. 미설정이면 버튼이 비활성화된다. 위치 버튼은 지도 상황실 필터로 연결된다.
- 앱 내 신고 알림은 `/report/:id`로 연결된다.

검증: TypeScript/프로덕션 빌드, lint, 백엔드 응답을 재현한 Playwright 테스트로 등록·취소·접수·연락처 열람·메모·완료 흐름과 320/393px 화면을 확인했다. 실제 서버 접수·문자 발송은 검증하지 않았다.
